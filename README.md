## Topic Overview
FlavorFind is an interactive React web application designed for exploring culinary recipes globally. Powered by **TheMealDB REST API**, it allows users to discover featured meals, search recipes by keyword, view preparation instructions, and manage a persistent list of favorite recipes using `localStorage`.

## Technologies Used
- **React 18** (Vite build tool)
- **React Router DOM v6** (Multi-screen navigation)
- **Bootstrap 5** (Responsive layout & component styling)
- **Lucide React** (UI Icons)
- **TheMealDB API** (External REST API integration)

## Setup & Local Run Instructions

1. Extract the project folder from `Ahsan_Ahsan_final-project.zip`.
2. Open terminal in the project directory.
3. Install dependencies:
   ```bash
   npm install
   ```
4. Run the development server:
   ```bash
   npm run dev
   ```
5. Open your browser at `http://localhost:5173`.
